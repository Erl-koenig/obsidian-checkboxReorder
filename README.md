# Checkbox Reorder

Reorders completed checkboxes to the end of their list.

![A demo of the plugin working](demo.gif)

## Installation

Install **Checkbox Reorder** from Obsidian's Community Plugins browser.

## Usage

- Press `Ctrl+P` or `Cmd+P` and run **Reorder Checkboxes in List**
- Optionally bind the command to a hotkey
- Use the **Top / Bottom** setting to choose where completed checkboxes move
- Half-checked `- [/]` checkboxes are placed between unchecked and completed checkboxes
